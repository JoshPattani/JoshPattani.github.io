ChromaFreq

ChromaFreq is an experimental listening instrument that translates sound into visible color, using real-time frequency analysis and wavelength mapping to explore the space between music, perception, and light.

Project note

Sound as visible structure

V2 keeps the original ATLAS color-study idea intact while replacing the prototype playback stack with a clearer Web Audio architecture. The engine analyzes local files, generated test tones, or live input, then maps frequency information into visible-light wavelengths and RGB values. Spotify is reserved for context only and is never treated as a raw audio source.
